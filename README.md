# The Blond — site

Site institucional do The Blond (Sorocaba), baseado no documento de Posicionamento & Identidade de Marca.

- `index.html` — página única, sem dependências de build. Abra direto no navegador ou publique em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).
- `assets/img/` — fotos do salão. Veja `assets/img/LEIA-ME.md` para os nomes de arquivo.
- WhatsApp: altere a constante `WHATSAPP` no final do `index.html` se o número mudar.
